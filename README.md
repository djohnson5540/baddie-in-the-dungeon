# Baddie in the Dungeon

Baddie in the Dungeon is a planned retro-style dungeon game created in Visual Basic using a WPF Application in Visual Studio.

The player will explore a pink-themed dungeon, collect treasure and a key, avoid enemies and traps, and reach the exit.

## Repository Structure

- `src/` — Visual Basic WPF project
- `assets/` — Images, sounds, and asset drafts
- `docs/` — Development and study documents
- `evidence/` — Screenshots and required proof

## Current Status

Week 10 preparation phase. The full game has not been built yet.
