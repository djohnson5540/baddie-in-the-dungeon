# Development Document

## Project and Brief

**Project title:** Baddie in the Dungeon  
**Developer:** Destiny Johnson  
**Technology:** Visual Basic WPF Application in Visual Studio  
**Genre and mood:** Pink retro dungeon adventure  

**Goal:** Create a dungeon game where the player collects treasure and a key, avoids enemies and traps, and reaches the exit.

**Target player:** Casual players who enjoy simple retro games.

## Required Deliverables

- Visual Basic WPF starter project
- Development Document
- Reference Study Notes
- Asset Manifest
- Test and Readiness Log
- At least three assets or labeled drafts
- Root README and `.gitignore`
- Discord preparation evidence
- At least four meaningful Git commits
- Public GitHub repository link

## Critical Requirements

- Week 10 is preparation only, not the complete game.
- The empty WPF project must open and run.
- The game must be an original adaptation rather than a copy of Breakout.
- Every asset must have a documented source and permission.
- The repository must open while signed out.
